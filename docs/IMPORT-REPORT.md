# Relatório de importação — 12/08/2026

## Material recebido

O arquivo exportado do Claude contém uma composição visual própria com 14 blocos editoriais, câmera contínua, telas desktop e celular, relatório e histórico. A duração autoral somada é de 59,1 segundos.

## Aproveitado

- Código JSX da composição visual.
- Engine/painel necessários para abrir a exportação.
- Logotipo e ícone presentes na exportação.
- Mapa de referências visuais usado pelo Claude.

## Excluído deste repositório

- Projeto V6 antigo que embutia `master-v4.mp4`.
- MP4 V4 de baixa qualidade.
- Vídeo externo usado apenas como inspiração.
- Capturas temporárias e arquivos duplicados.

## Decisão

A V8 Remotion continua sendo a base de produção porque é nativa e não empilha renders antigos. A exportação do Claude fica como referência paralela para incorporar seletivamente câmera, enquadramento, transições e composição.
