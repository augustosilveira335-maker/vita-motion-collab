# Claude — instruções deste projeto

Você está no projeto independente `vita-motion-collab`, não no aplicativo do cliente.

Trabalhe somente aqui. Não faça qualquer escrita no repositório do aplicativo real. Se precisar verificar uma tela, consulte-a somente para leitura e registre no PR quais referências visuais foram usadas.

Antes de editar:

1. leia `AGENTS.md`;
2. crie uma branch `claude/<tema>`;
3. informe quais arquivos pretende modificar;
4. mantenha renders, ZIPs, `node_modules` e QA fora do Git;
5. rode `npm run lint` dentro de `remotion/` quando alterar a V8.

O conteúdo em `claude-reference/` é uma referência exportada. A produção principal fica em `remotion/`. Aproveite ideias e correções visuais de forma rastreável; não substitua a V8 por MP4 antigo.
